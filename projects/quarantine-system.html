Quarantine Patients
Management System

Healthcare Data Management with Java and OOP

Project Context

During the COVID-19 pandemic, efficient management of quarantine patients and healthcare resource allocation became critical. This project developed a Java-based desktop application to help healthcare administrators track quarantined patients, identify available doctors by location, and facilitate rapid coordination during health emergencies.

Problem Statement

Healthcare facilities faced challenges during the pandemic:

  • Patient Tracking: Manual spreadsheets couldn't scale with patient volume
  • Resource Allocation: Difficult to match patients with available doctors by location
  • Contact Information: Critical time wasted searching for doctor contact details
  • Data Consistency: Multiple disconnected systems led to errors
  • Quick Access: Slow retrieval of information during emergencies

Project Objectives

  • Create centralized database for patient and doctor information
  • Implement location-based search for available healthcare providers
  • Provide quick access to doctor contact information
  • Use object-oriented design for maintainable, extensible code
  • Build intuitive GUI for non-technical healthcare staff
  • Ensure data consistency and validation

System Architecture

The application follows a three-tier architecture:

1. Presentation Layer (GUI)

  • Framework: Java Swing for desktop interface
  • Components: Tables, search forms, data entry panels
  • Navigation: Tab-based interface for different modules
  • Visual Feedback: Status indicators, validation messages

2. Business Logic Layer

  • Patient Management: Add, update, search patient records
  • Doctor Management: Maintain doctor availability and specializations
  • Search Algorithm: Location-based matching of patients to doctors
  • Validation: Data integrity checks, input validation

3. Data Layer

  • Storage: File-based persistence (CSV/text files)
  • Data Structures: ArrayList, HashMap for in-memory storage
  • CRUD Operations: Create, Read, Update, Delete functionality

public ArrayList findDoctorsByLocation(String patientLocation) {
    ArrayList availableDoctors = new ArrayList<>();
    
    for (Doctor doc : doctors) {
        if (doc.getLocation().equalsIgnoreCase(patientLocation) 
            && doc.isAvailable()) {
            availableDoctors.add(doc);
        }
    }
    
    // Sort by specialization priority if needed
    return availableDoctors;
}

Data Structures & Algorithms

Data Structures Used

  • ArrayList: Dynamic storage for patients and doctors
  • HashMap: Fast lookups by ID (O(1) average case)
  • TreeSet: Sorted unique locations for dropdown menus

Search Algorithms

  • Linear Search: Location matching (small dataset, simple implementation)
  • Binary Search: Sorted patient ID lookups (for large datasets)
  • Filtering: Multiple criteria (location + availability + specialization)

Challenges & Solutions

Challenge: Data Integrity Across Sessions

Solution: Implemented auto-save on every update operation. Added data validation before writing to file. Implemented backup mechanism to prevent data loss on crashes.

Challenge: Case-Insensitive Location Matching

Solution: Standardized all location strings to lowercase before comparison. Added autocomplete dropdown to prevent typos and inconsistent naming.

Challenge: GUI Responsiveness

Solution: Moved file I/O operations to background threads. Implemented progress indicators for long-running operations. Used SwingWorker for async tasks.
